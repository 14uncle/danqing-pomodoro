## 详细说明

### 🕯️ 专注，可以是一场旅行

打开丹青番茄钟，选择一个世界：

- **篝火旁**——噼啪作响的火焰，夜色温暖
- **海边**——潮汐起伏，心随浪静
- **雨天**——雨丝敲窗，思绪沉淀
- **山顶**——云海翻涌，万籁俱寂
- **森林**——鸟鸣幽径，绿意盎然
- **铁匠铺**——炉火通红，锻打节奏
- **洞穴**——萤光闪烁，与世隔绝
- **夜市**——灯火阑珊，人间烟火
- **火车**——窗外掠过，一站一景

每个场景都有**独立 shader 动画**和**真实环境音**，不是静态壁纸，是一个呼吸着的小世界。

### ⏱️ 经典番茄钟，专注不复杂

25 分钟专注 / 5 分钟休息 / 15 分钟长休息——经典节奏，开箱即用。也支持自定义时长。
全局快捷键 `Ctrl+Shift+S` 一键开始/暂停，不打断工作流。

### 📊 数据，让坚持看得见（应用内购买解锁）

- 今日 / 本周 / 累计专注时长一目了然
- 年度报告深度洞察你的专注模式
- CSV / JSON 导出，你的数据你做主
- 本地 JSON 存储，不上传，不追踪

- 纯 Rust 编写，无运行时依赖

### 💬 用户可能会问

**Q: 数据会上传吗？**
A: 不会。所有数据存在本地 `%APPDATA%/danqing/` 目录，纯 JSON 文件，可以随时查看、导出、删除。

**Q: 内购是一次性的吗？**
A: 是。买断制，一次购买永久解锁，同一微软账户多设备共享。

**Q: 支持多显示器吗？**
A: 窗口可以拖到任意显示器上。
