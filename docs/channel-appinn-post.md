## 帖子正文（可直接复制）

**标题**：

```
【开发者自荐】丹青番茄钟：9 个沉浸场景 × 实时动效 × 环境音，让专注不再靠忍耐
```

**正文**：

```
做这个的起因很简单：我用遍了市面上的番茄钟，它们都能计时，但没一个让我「愿意」打开。

大多是一个数字加一根进度条，倒计时结束弹个提示。可专注本身已经够难了，界面不该再消耗一遍意志力。

所以我想试试另一种做法：让番茄钟变成一个「可以待着」的地方。

**9 个场景，每个都是独立写的 shader 实时动效**——不是循环播放的视频或 GIF，是真正在实时渲染的粒子、光照与流体：
篝火、雨、山、森林、海、铁匠铺、洞穴、夜市、火车。

配上真实录制的环境音：篝火有柴火的爆裂声，铁匠铺有锤打声，夜市有人声鼎沸。

**关于收费**：免费版已经包含篝火、海两个完整场景 + 番茄钟计时 + 全局快捷键，开源免费，直接下载就能用。
完整版（其余 7 个场景 + 专注统计 + 年度报告 + CSV/JSON 明文导出）是 **¥18 买断**，在微软商店，或者你自己 clone 下来编译也行。

数据全部存在本地，不联网、不注册、不登录、无广告、无遥测。

**技术上的一个私心**：这个界面不是用现成 UI 框架搭的——我从零写了一个 Rust 的 UI 引擎（winit 做窗口、wgpu 自绘），因为要做全屏实时动效和自定义排版，现成框架在好几个地方挡路。渲染管线、文本排版、组件树都是自己写的。（引擎也开源：https://github.com/14uncle/danqing）

- GitHub（免费版直接下载，开源）：https://github.com/14uncle/danqing-pomodoro
- 微软商店（完整版 ¥18 买断）：https://apps.microsoft.com/detail/9P3W6W1SR6DS

系统要求：Windows 10 1809 及以上。解压即用，无需安装。
```
