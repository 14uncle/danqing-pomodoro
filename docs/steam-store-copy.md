## 详细描述 (About This Game)

### 🕯️ 专注，可以是一场旅行

打开丹青番茄钟，选择一个世界：

- **篝火旁**——噼啪作响的火焰，夜色温暖
- **海边**——潮汐起伏，心随浪静
- **雨天**——雨丝敲窗，思绪沉淀
- **山顶**——云海翻涌，万籁俱寂
- **森林**——鸟鸣幽径，绿意盎然
- **铁匠铺**——炉火通红，锻打节奏
- **洞穴**——萤光闪烁，与世隔绝
- **夜市**——灯火阑珊，人间烟火
- **火车**——窗外掠过，一站一景

每个场景都有 **独立 shader 动画** 和 **真实环境音**，不是静态壁纸，是一个呼吸着的小世界。

---

### ⏱️ 经典番茄钟，专注不复杂

25 分钟专注 / 5 分钟休息 / 15 分钟长休息——经典节奏，开箱即用。也支持自定义时长，按你的节奏来。

全局快捷键 `Ctrl+Shift+S` 一键开始/暂停，不打断工作流。

---

### 📊 数据，让坚持看得见

付费版解锁 **数据统计** 和 **年度报告**：

- 今日 / 本周 / 累计专注时长一目了然
- 年度报告深度洞察你的专注模式
- CSV / JSON 导出，你的数据你做主
- 本地 JSON 存储，不上传，不追踪

### 💬 用户可能会问

**Q: 和 Wallpaper Engine 有什么区别？**
A: Wallpaper Engine 是壁纸引擎，需要自己找/做壁纸。丹青番茄钟是一个完整的专注工具——场景、音效、计时、统计，开箱即用。

**Q: 数据会上传吗？**
A: 不会。所有数据存在本地 `%APPDATA%/danqing/` 目录，纯 JSON 文件，你可以随时查看、导出、删除。

**Q: 支持多显示器吗？**
A: 窗口可以拖到任意显示器上。未来版本计划支持固定到指定显示器。

**Q: 会支持更多场景吗？**
A: 会。后续通过免费更新或 DLC 增加新场景。

## 配置需求

**最低配置:**
- 操作系统: Windows 10 (64-bit)
- 处理器: 任意支持 D3D12 的 CPU
- 内存: 256 MB RAM
- 显卡: 支持 DirectX 12 的显卡
- 存储空间: 100 MB 可用空间

**推荐配置:**
- 操作系统: Windows 11
- 内存: 512 MB RAM
- 显卡: 独立显卡（更流畅的 shader 渲染）
